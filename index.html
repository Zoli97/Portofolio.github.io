    QR Code Generator

    This is a web application that let users to create a scannable QR code from any URL. Users enter a link, choose an output size (from 100x100 to 700x700) and generate a QR code image that can be used to give smartphone users quick, easy access to a website. Built with HTML, Tailwind CSS and Vanilla Javascript with QRCode.js library, clean and responsive interface.

    URL Shortener is a simple web app that converts long URLs into short, easy-to-share links. Users paste in a long URL, and the app generates a compact shortened version that redirects to the original destination when visited. Built with a backend framework (like Node.js/Express) and a database (like MongoDB via Mongoose) to store and manage the URL mappings, with routes handling the creation and redirection logic, without UI.
